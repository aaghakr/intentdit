Conference/Journal 2023

Intent-Aware Layout Generation with Natural Language Control

Abdul Waheed Aagha
Soongsil University
Conference on Computer Vision and Pattern Recognition 2024
Paper Supplementary Code Demo

Our intent-aware layout generation framework enables natural language control for creating layouts with spatial guidance. Watch how our system generates layouts based on text descriptions while maintaining design principles and visual hierarchy.

Abstract

We introduce the first text-controllable transformer-diffusion framework for layout generation, enabling natural language specification of design requirements while maintaining high-quality output through intent-aware spatial guidance. Our multi-modal approach integrates textual semantics with visual features while preserving content-graphic balance principles. We develop a design-specific intent detection system that captures spatial importance based on layout context rather than generic visual saliency. Our framework extends existing PKU and CGL layout datasets with comprehensive natural language descriptions, creating the first publicly available text-controlled layout datasets with over 300,000 natural language descriptions across 4 distinct prompt styles. Through extensive experiments across 24 configurations (2 datasets × 2 encoders × 6 spatial guidance combinations), we demonstrate significant improvements in layout quality, user satisfaction, and semantic understanding compared to existing methods. Our work establishes a new research direction in text-controlled layout generation and provides open-source datasets to benefit the research community.

Unconditional Layout Generation: Our framework generates diverse layouts without any constraints, demonstrating the model's ability to create varied and realistic designs.

Text-Controlled Generation: Natural language prompts guide layout creation, enabling intuitive design specification through descriptions like "Create a poster with a logo in the top-left corner."

Intent-Aware Spatial Guidance: Our system uses design-specific intent detection to understand spatial importance, providing more accurate guidance than generic visual saliency.

Multi-Modal Integration: Cross-modal attention mechanisms effectively integrate textual semantics with visual features while preserving content-graphic balance principles.
